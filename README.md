#📊 Decode Labs Project 1 — Data Cleaning, EDA & Excel Dashboard
📌 ## Project Overview

This project was completed as part of my Decode Labs Data Analytics training.

The project involved working with an e-commerce dataset and applying fundamental data analytics techniques using Microsoft Excel.

The project was completed in two main tasks:

  ###Task 1: Data Cleaning
Task 2: Exploratory Data Analysis (EDA) and Descriptive Statistics

The cleaned and analyzed data was then used to create an Excel dashboard to present the findings visually.

🎯  ##Project Objectives

 ##The objectives of this project were to:

Clean and prepare the dataset for analysis.
Identify and correct data quality issues.
Perform descriptive statistical analysis.
Calculate measures such as Mean, Median, and Count.
Explore the dataset to understand its characteristics.
Create visualizations from the analyzed data.
Develop an Excel dashboard to communicate the results clearly.
